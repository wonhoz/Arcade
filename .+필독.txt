  git 으로 따라오지 않는 것만 적었다. git pull 만으로는 끝나지 않는다.
  1번과 2번을 안 하면 프론트엔드나 게임이 제대로 동작하지 않는다.


--------------------------------------------------------------------------------
  0.  최신 내용 받기
--------------------------------------------------------------------------------

      cd /d D:\AttractMode
      git pull


--------------------------------------------------------------------------------
  1.  실행은 attract.exe 가 아니라  attract.bat            ★ 가장 중요
--------------------------------------------------------------------------------

  Attract-Mode 2.7.0 부터 attract.exe 가 콘솔 앱으로 바뀌었다.
  그냥 실행하면 이렇게 된다.

      - 검은 콘솔 창이 같이 뜬다
      - last_run.log 가 만들어지지 않는다  ->  문제가 생겨도 원인을 알 수 없다

  바탕화면 바로가기와 시작프로그램을 attract.bat 으로 바꿀 것.

    [ 직접 바꾸기 ]
      바로가기 우클릭 - 속성
        대상 :  D:\AttractMode\attract.exe   ->   D:\AttractMode\attract.bat
        실행 :  최소화

    [ 한 번에 바꾸기 - PowerShell 에 그대로 붙여넣기 ]

      $sh = New-Object -ComObject WScript.Shell
      @("$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup",
        "$env:USERPROFILE\Desktop", "$env:PUBLIC\Desktop") | ForEach-Object {
        Get-ChildItem $_ -Filter *.lnk -ErrorAction SilentlyContinue | ForEach-Object {
          $s = $sh.CreateShortcut($_.FullName)
          if ($s.TargetPath -like "*\attract.exe") {
            $s.TargetPath = "D:\AttractMode\attract.bat"
            $s.WorkingDirectory = "D:\AttractMode"
            $s.WindowStyle = 7
            $s.Save(); "바꿈: $($_.FullName)"
          } } }

    ※ 설치 경로가 D:\AttractMode 가 아니면 위 경로를 고쳐서 쓸 것.


--------------------------------------------------------------------------------
  2.  Cemu 롬 폴더 이름 바꾸기
--------------------------------------------------------------------------------

      emulators\Cemu\Roms\Tekken
          ->  emulators\Cemu\Roms\Tekken Tag Tournament 2

  롬 폴더는 git 추적 대상이 아니라 따라오지 않는다.
  안 바꾸면 "철권 태그 토너먼트 2" 가 실행되지 않는다.


--------------------------------------------------------------------------------
  3.  확인
--------------------------------------------------------------------------------

      powershell -ExecutionPolicy Bypass -File tools\validate.ps1

      FAIL 0 / WARN 0  이면 정상.

      "환경" 항목은 이 장비에 없는 롬·아트웍을 알려주는 것이라
      0 이 아니어도 된다. 오히려 설치할 때 체크리스트로 쓰면 된다.


================================================================================
  알아두면 좋은 것
================================================================================

  * 게임을 한 번 실행하면 입력 설정·세이브가 바뀌어 git status 가 지저분해진다.

        powershell -ExecutionPolicy Bypass -File tools\reset-runtime.ps1

          인자 없이       무엇이 바뀌었는지 보여주기만 함 (안전)
          -Config -Clean  평소 정리. 설정만 되돌리고 로그·통계 삭제
          -Saves          세이브까지 되돌림  ->  게임 진행이 사라진다. 주의

  * 문제가 생기면 last_run.log 부터 본다. 레이아웃 오류·설정 경고·롬 로딩이 전부 여기 남는다.
    로그가 갱신돼 있지 않다면 attract.exe 를 직접 실행한 것이다. 1번을 다시 확인할 것.

  * 게임을 추가하거나 설정을 고쳤으면 validate.ps1 을 한 번 돌린다.

  * 공통 변경은 develop 브랜치에서 한다. 장비 브랜치에서 직접 고치면
    다른 장비로 옮기기 어려워진다.

  * 자세한 내용
        CLAUDE.md          작업 지침서 (구조·경로 규칙·작업 레시피·진단 순서)
        README.md          새 장비 설치 절차·조작키
        docs\ISSUES.md     알려진 문제와 개선 과제
